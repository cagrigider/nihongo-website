# NihonGo Website

Official website for the NihonGo Japanese learning app, hosted on GitHub Pages.

## About NihonGo

NihonGo is a comprehensive Japanese language learning app that combines AI-powered conversations, interactive kana practice, and personalized vocabulary building to help you master Japanese effectively.

## Features

- 🤖 **AI Conversation Practice** - Realistic Japanese conversations with intelligent AI
- 📚 **Smart Kana Learning** - Interactive hiragana and katakana lessons
- 🎯 **Personalized Vocabulary** - Context-rich word learning with progress tracking
- 📊 **Progress Analytics** - Visual progress indicators and learning streaks
- 🌍 **Cultural Context** - Real-world usage examples and cultural insights
- 📱 **Cross-Device Sync** - Seamless progress synchronization across devices

## Website Pages

- **Home** (`index.html`) - Main marketing landing page
- **Support** (`support.html`) - FAQ and contact information
- **Privacy Policy** (`privacy.html`) - Data protection and privacy information
- **Terms of Service** (`terms.html`) - App usage terms and conditions

## Local Development

To preview the website locally:

1. Clone this repository
2. Open `index.html` in your web browser
3. Or use a local server: `python -m http.server 8000`
